# The Best Wario Game Ever Made

## What we did

- Built a WarioWare-style Godot game using the chosen background.
- Added a title screen with Start Game, Settings, and Quit.
- Added two minigames: a platformer garlic-collecting challenge and a timed garlic-clicking challenge.
- Added timers, lives, success screens, game-over screens, and replay flow.
- Configured and tested the project for HTML5 export.
- Published the playable demo on itch.io.
